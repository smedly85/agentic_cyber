# Performance-only inclusion repair: preimplementation note

Written before candidate implementation. Reference: `rust_mir/inclusion.py`, SHA-256 `12ba550d3f52f20f989ff596d292bc4ebdb2608ccc5fcd47beef16ad4d40d871`. The reference file, extraction, finalizer, classifier, and frozen scientific inputs are not changed. The candidate is separately selectable and has no default-backend effect.

## Observed hot paths

`analyze.collapse` (reference lines 37–50) uses `cells_by_local[(instance, local)]` to enumerate that local's cells, unions every `values[cell]` into a fresh set, then unions that temporary into the root. Its repeated cost is proportional to the sum of member-set cardinalities, even when the group already collapsed. It does **not** scan unrelated locals. It also accumulates source spans, reasons and field names on every call; those observable effects cannot be skipped.

`analyze.copy` (104–118) resolves destination/source places, materializes an operand union, scans all fields of each source local, filters projections by prefix, and unions entire source sets into destinations. `store` (96–102) repeats `set.update` even when source contents are unchanged. Costs include full set cardinalities and field counts per copy, per sweep. New facts, newly created empty cells, newly reachable destination cells, and a collapse changing canonical destinations are separate invalidation events.

`locations`, pointer metadata (168–171), and dyn receiver handling (230–236) repeatedly filter mutable sets by token kind (`type`, `address`, `erased_address`, `function`). The lookup key is a concrete cell plus token kind, or an operand resolved to a group of cells. An exact index must be maintained on every insertion. A cached operand must also preserve read-created cells and union-collapse side effects; memoizing a mutable operand by source syntax alone is invalid.

## Proposed exact mechanisms and proof obligations

1. **Collapse absorption invariant.** On the first collapse, union all existing raw member sets into the canonical root exactly as before. Thereafter every `store` canonicalizes writes into that root. Old non-root member sets cannot gain facts. Newly read-created non-root cells are empty. Consequently repeating the member union adds nothing. Skip that union after the first collapse, but always record spans/reasons and incrementally record newly created field names. No fields are merged before an actual reference collapse operation.
2. **Versioned set transfer.** Each mutable cell set has a monotone generation. A source-cell/destination-canonical-cell relation may skip transfer only if that source generation was already propagated to that destination. Destination growth cannot invalidate this fact because there are no deletions. Destination canonical identity is part of the key. Preserve cell creation even for empty sources. If delta history is used, it must contain exactly the additions since that relation's cursor; no arbitrary pruning.
3. **Exact kind indexes.** Index each inserted token under its first tuple element, without removing it from the original set. Filtering a cell by kind returns exactly this indexed subset. Direct raw-field reads must remain raw reads; they must not silently canonicalize. No abstract object or token is dropped.
4. **Projection lookup.** A local's field-membership version can invalidate cached ordered prefix matches. Snapshot membership must correspond to the original `list(cells_by_local[...])` at that operation; fields created during a copy are not retroactively added to its snapshot. Avoid caching a mutable set iteration order across membership changes.

The first candidate retains the original function/constraint/call iteration structure and all 256 full sweeps. It introduces no worklist or heuristic cap. Convergence remains the same `changed` test at the end of a full sweep; cap exhaustion remains fail-closed. Exact duplicate-work suppression inside a sweep must preserve both facts and observable provenance. A worklist redesign is unnecessary unless these local repairs prove insufficient.
