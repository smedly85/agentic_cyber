# RUPTA controlled feasibility criteria

Recorded before building RUPTA or observing any RUPTA graph. Prior MIR/SVF
reports and fixture source have been inspected. Existing expectations and
their amendments are reused unchanged, including exact target sets and
application-subsequence path rules. This is not a blind experiment.

1. Build unmodified upstream at a recorded commit with its pinned nightly,
   locked dependencies and authenticated component downloads. Keep all
   installations and outputs in build/rupta-v1; no default toolchain changes.
2. Start with direct, nested, recursive, function-pointer, two-field pointer
   and dynamic-trait examples. The two-field call must target only target.
3. Then evaluate all 35 existing Rust programs, separately under ander and
   cs (default context depth 1), twice in fresh output directories. Optional
   cs depth 2 must be reported separately. Timeout: 180 seconds per analysis;
   address-space cap: 16 GiB. Build timeout: 1200 seconds.
4. Every required relation, exact adjudicated target set, absence, instance
   count and independently specified depth/path must hold. False targets,
   missing targets, unreported unresolved sites, unsupported features,
   incomplete output, failures and timeouts cannot pass.
5. Preserve monomorphized identities and call direction. Audit exporter
   context projection, boundary information and callsite representation.
   Do not label unknown edge kinds direct or synthesize missing edges.
6. Use backend.finalize_semantic_graph only when edge kinds/identities satisfy
   its contract. Retain all shim/library nodes. Dmax is maximum finite shortest
   distance, not longest path. Normalized output must repeat identically.
7. Assess historical compatibility read-only, including original editions,
   locks, compiler and dependency requirements. No historical graph/depth runs.
8. Verify protected artifacts and existing regression tests remain unchanged.

Any necessary failed gate blocks historical measurement. A build/toolchain
failure stops dependent graph experiments; all unrun fixtures remain explicitly
not run with null measurements. Precision failures may be catalogued across
the already authorized controlled corpus, but never authorize historical work.
No algorithm patches, source changes, dependency upgrades or borrowed edges
may turn canonical failures into successes. Compatibility experiments require
separate provenance and cannot replace canonical outcomes.
