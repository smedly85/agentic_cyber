# Rust-only lightweight MIR graph, version 1

This is a new, explicitly narrower Rust-only method, not an amendment claiming equality to the inclusion solver. Neither inclusion solver is used. Prior method-v1, solver diagnostics, calibration, C results, mappings and population remain unchanged.

Edges require rustc's resolved_instance/drop_instance identity, or an exact concrete function constant exported as the indirect call operand. Monomorphized generic, static trait, closure and shim calls are included when they have that concrete evidence. A dyn_candidates inventory is not a callsite target-set proof, even if it has one element: unresolved dyn calls remain unresolved. No local or whole-program points-to inference, signature matching, implementation enumeration or dynamic-trace augmentation is performed.

Every extracted Instance remains a node. A compiler-resolved callee whose body is absent is retained as an explicitly labeled boundary node; it has no invented outgoing edges. Intrinsic, std/core, shim and drop nodes are not contracted. Unresolved calls remain callsite records without invented edges.

The existing deterministic graph finalizer supplies BFS paths and distances. Vulnerability depth is the minimum reachable distance among legitimate Instances of the frozen source mapping, with source/DefPath/span matching unchanged. Maximum depth is the maximum finite shortest BFS distance, not a longest path. Both metrics describe the retained known-edge graph only. An unresolved call may hide targets or shortcuts; these are not claimed to equal complete semantic may-call depths, nor to be bounds on whole-program maximum depth.

Known paths remain measurable even if another reachable site is unresolved. Each context reports reachable unresolved sites and missing-body boundaries. If no mapped target is reached, report unresolved_with_indirect_boundary when a reachable indirect boundary exists; this is a potential missing-route attribution, not proof that that call reaches the target. Distinguish missing mapping, unavailable platform/build, body boundary, and unreachable-with-no-observed-boundary. Failures never become zero. Do not fabricate causal counts of which indirect site reaches an absent target.

Use the frozen 45-CVE population, 49 verified function records / 51 executable-platform observations, historical revisions, entry identities and mappings. Preserve the two unresolved mappings and one not-applicable case. Reuse immutable compiler-extracted MIR snapshots with their original edition/build/dependency provenance and verify their hashes; no source recompilation or dependency migration is needed. Run the live runtime gate immediately before each lightweight graph invocation. Recompute graphs independently twice; require normalized byte equality.

Validation uses the existing 103 controlled/focused/memory/operation/adapter/transitive/calibration extracted inputs (no synthetic inclusion-constraint-only tests). Before history, require every retained call to agree with compiler evidence, every unsupported target relation to remain explicitly unresolved, no invented targets, deterministic BFS/output, and the required direct/recursion/generic/static-trait/concrete-closure construct cases to match their controlled expectations. Report coverage losses against frozen target relations without treating expected unresolved indirect cases as invented successful resolutions. Freeze the source/configuration and validation evidence before historical processing. No C/Rust comparability classification or hypothesis test is claimed.
